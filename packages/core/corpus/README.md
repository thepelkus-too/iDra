# Corpus

Hand-written Hydra sketches (plus a few deliberately awkward ones) that every part of the project must be able to
open, edit and export without loss. They are original to this repository and AGPL-3.0 licensed with it; the
examples in the upstream `hydra-examples` repository carry no license file, so they are intentionally not copied.

`24-broken.js` has a syntax error on purpose. `33-crlf.js` has Windows line endings (see `.gitattributes`).
